# Navigate — standalone repo root

This directory is the **Navigate** app (`TheMarkkBradonCollective/Navigate`).

GitHub releases for this app are tagged `navigate-v*` and include the APK release zip.

## Quick start

```bash
npm install
npm run dev
npm run build && npm run build:apk
```

## Releases

Download the latest APK from [GitHub Releases](https://github.com/TheMarkkBradonCollective/Navigate/releases) or install via [MBC App Store](https://themarkkbradoncollective.github.io/main/download/).

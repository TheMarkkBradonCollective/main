How it works

Store app · one-time setup

  1. Get MBC Store — tap the banner above and install the store APK (allow installs from your browser when Android asks).
  2. Open MBC Store — the store loads this catalog and knows what's already on your phone.
  3. Install or Update — tap the button on any app. Confirm in the Android installer if prompted.
  4. Come back here — refresh the catalog anytime; updates show automatically when a new build ships.

These are my own apps, signed and hosted on each project's deployment. Sideloading outside Google Play is normal for indie catalogs — only install apps you trust.

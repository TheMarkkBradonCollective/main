How to install

Android sideload · 60 seconds

  1. Download the APK from the card above (tap Download APK).
  2. Allow installs — Android may ask you to allow installs from your browser or Files app (Settings → Security → Install unknown apps).
  3. Open the file from your notification shade or Downloads folder and tap Install.
  4. Update later — come back here, hit Refresh listings, and download the newest APK. Install over the old one to update.

These are my own apps, signed and hosted on each project's deployment. If your phone warns about an unknown source, that's normal for sideloading outside the Play Store — only install apps you trust.
